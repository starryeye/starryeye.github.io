# 기술 표준 번역 고지

RFC 6749, RFC 6750, RFC 7009, RFC 7519, RFC 7636, RFC 7662, RFC 8414, RFC 8693, RFC 9068, RFC 9700의 비공식 AI 한국어 번역본입니다.
공식 원문과 발행본의 저작권·이용 조건이 우선하며, 이 저장소 테마의 LICENSE를
RFC 본문이나 포함 자산 전체에 일괄 적용하지 않습니다. 각 글의 원문 링크와
원래 저작권 고지를 확인해 주세요. 번역에는 오류가 있을 수 있으며 공식 표준을 대체하지 않습니다.

읽기용 편집은 supertranslator로 생성했습니다. 기존 AI 번역을 재사용하고,
본문 폭·글자 크기·문단 연결·목록 등을 정돈했습니다. 원래 원문·번역 검토와
읽기용 편집 검토 기록은 각 글 상단에서 확인할 수 있습니다.

기존 블로그 글 2개는 요청에 따라 공개 글에서 제거했습니다. 저장소의 Git 이력은
그대로 보존했으며 강제 푸시나 이력 삭제는 하지 않았습니다.
